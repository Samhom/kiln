# Kiln 窑

本地 JSON 工作台。贴进接口响应或 NDJSON 日志，可以展开成树、收成表、点出路径，也可以把两份原文比出增删改。

路径、管道和 `select` 的写法借鉴 jq；树里按路径跳转借鉴 jless；打开一份文档就能折叠查看，借鉴 fx。过滤只实现了下面这一小段，由窑自己的解析器计算，不会把输入交给脚本。

## 本地启动

需要 Node.js 20 或更新版本，没有运行时依赖。

```sh
npm start
```

打开 http://127.0.0.1:4329/ 。默认只监听本机。`HOST` 和 `PORT` 可以改地址和端口。

```sh
npm test
```

## 怎么用

- 看一份：把 JSON 贴进左边，或拖进 `.json`、`.ndjson`、`.jsonl`、`.txt`。超过 8MB 的文件不会打开。解析失败时，点「跳到出错处」会选中那一行。
- 比两份：左边和另一份按字段比较。树形、表格和文本仍只看左边。
- 点树形或表格里的一行，上面的路径会变成一层层按钮。点前面某一层就回到那里。复制路径、复制指针和复制值分别拿走三种结果。「下载结果」把当前过滤后的整份结果存成 `kiln-result.json`。
- 过滤框在停下输入后更新右边。下方会按这份 JSON 的字段给出可点的过滤；还没有原文时，先给出几条通用例子。回车或「记下来」会把成功的过滤留在下方。多条结果会收成数组，方便切到表格里排序。
- 「在结果里找」按键或值定位。回车或「下一处」会展开那一行。树形可以全部展开或全部收起；一次最多先画出 800 个节点。不在输入框里时，方向键可以上下移动，向右展开，向左收起。
- 比两份会按字段和数组下标列出差异，最多先列出 400 处，并可以只看增、删或改。数组按下标对齐，不按内容配对。

页面上的「订单」「日志」「两份配置」是三份可以直接点开的例子。

## 过滤

```
.buyer.city
.items[0]
.items[-1]
.items[]
.items[] | select(.price >= 80)
select(.name ~= "杯")
.["买家"]
.items | length
keys
type
```

比较符是 `==`、`!=`、`>`、`<`、`>=`、`<=`、`~=`。`~=` 只判断字符串包含。右侧只能是字符串、数字、`true`、`false` 或 `null`。和 jq 一样，`select` 里只有 `false` 和 `null` 算不成立。最多串 12 段，结果超过 10000 条就会停下来。

## 数据留在页面里

服务只按固定名单返回窑自己的页面和脚本，不接收原文，也不保存文件。最近用过的过滤写在这个标签页的 `sessionStorage` 里，原文不写入。
